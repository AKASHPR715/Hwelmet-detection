# 📱 WhatsApp Activity Analyzer

This project analyzes user activity from a WhatsApp-like chat dataset. It uses machine learning and data visualization to uncover patterns such as user engagement, most active users, and peak activity hours. It also predicts user engagement levels and classifies users based on their behavior.

---

## 🔍 Features

- ✅ Loads and processes chat activity data from a CSV file
- ✅ Aggregates user statistics: total hours, message counts
- ✅ Calculates engagement levels (messages/hour)
- ✅ Identifies the most active user and their most active hour
- ✅ Performs **Linear Regression** to predict engagement
- ✅ Classifies users into **Low**, **High**, or **Medium** engagement using **Random Forest**
- ✅ Visualizes user engagement and model performance using **matplotlib**

---

## 🧪 Technologies Used

- **Python 3**
- **pandas** – data manipulation
- **scikit-learn** – machine learning
- **matplotlib** – data visualization
